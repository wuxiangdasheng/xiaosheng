# 大圣：视觉与行为

本文件是大圣的唯一权威。

## 外观校准

同台镜提示词只使用短识别词：

`戴橙色圆框眼镜、白T左胸橙色X的大圣`

完整外观只用于校准，长相由 `references/IP.jpeg` 锁定：

```text
人物（大圣）：30岁亚洲男性，圆中带方的脸、额头宽；头顶碎短竖起的短发，两侧推短鬓角；圆形橙色金属丝框眼镜；下巴有明显稀疏胡茬；左耳一枚圆形小耳环；白色短袖 T 恤，左胸橙色字母 X；肥款白色长裤；深色帆布鞋，oversize 风格。极简手绘线稿与平涂，深蓝色线勾勒轮廓；头发、胡茬只勾线不填色。表情安静关切，眉头松开。
```

完整外观不进入提示词。文字与图冲突时，以 `references/IP.jpeg` 为准，修改本文件的校准文字，不改图。

## 角色与出场

大圣是全片的主叙述者：文案的声音出自他。他通常在画外叙述，让灵体把叙述的内容演到画面上；独演镜中完全不存在。当他入画（同台镜），他用动作对灵体表达疗愈、支持、讲解、引导、总结或安抚——动作完成后，本镜的事情并没有消失，只是灵体不再独自扛着；大圣提供关系、方向和承托，不替灵体做最终决定。信息图镜中他担任讲解者：在图解版式中向观众讲解，人物位随版式而定（见 `references/排版.md` 版式用例），由灵体的变形提示指出重点。

每次入画都让观众读到大圣从何处进入或如何靠近：从侧方走来、从空间深处出现、停在灵体身边，或用其他自然的姿态建立关系。入口服务于本镜的环境和动作，不凭空出现在画面中央。

## 同台动作示例

大圣同台的行为覆盖六种意图：疗愈、安抚、支持、引导、讲解、总结；陪伴是在场类的行为之一。以下示例用于理解意图如何落成身体行为，不是封闭菜单，可按文案设计其他自然的动作：

| 意图 | 动作 | 远景中的成立方式 |
| --- | --- | --- |
| 疗愈 | 揉 | 用轻柔、持续的动作表达放松 |
| 疗愈 | 哄睡 | 用守在身边、轻拍或陪着躺下表达安放 |
| 安抚 | 摸头 | 用轻柔手势表达安慰 |
| 安抚 | 拍 | 用有节奏的轻拍表达鼓励和稳定 |
| 安抚 | 依偎 | 用贴近的身体关系表达承托 |
| 在场（陪伴） | 陪伴 | 用靠近、等待、并肩或共同停留表达在场 |
| 在场（陪伴） | 陪玩 | 通过共同朝向、共同操作或共同移动表达重新参与生活 |
| 支持 | 递 | 把物件、方向或下一步交到灵体面前 |
| 支持 | 托住 | 用环抱或承接的姿态接住失重与倾倒 |
| 引导 | 指向 | 抬手臂指明方向或目标 |
| 引导 | 回头等 | 先行两步停下，回头等灵体跟上 |
| 引导 | 牵手 | 用牵引和同行表达共同前进 |
| 讲解 | 示范 | 亲手把一件事做一遍给灵体看 |
| 讲解 | 指图 | 在图解版式上逐个指向图元 |
| 总结 | 并肩回望 | 与灵体一起回头看走过的路 |
| 总结 | 收拢 | 把散落的物件归置到一起，表达告一段落 |

动作可以由进入、靠近、停留、照看、分享和继续行动组成一段连续姿态，也可以直接承担解释、引导或总结。动作的强弱、距离和景别根据本镜需要自然安排；远景中用身影、距离、方向和轮廓关系表达，较细的动作则允许适度靠近以保证可读。

动作应当满足（叙事同台镜；信息图讲解镜以讲解清晰为准）：

1. 做完后，本镜的事情还在——动作不消除它。
2. 动作明确冲着灵体而来。
3. 不需要画清手指、脸或五官也能读懂。

## 行为不变量

- 大圣的回应建立在灵体当下的状态和动作上：给它时间靠近，也可以主动提供方向。
- 视线落在灵体、共同对象或行动方向上，不看镜头；表情保持安静关切。
- 动作保持自然、克制和可读，服务于本镜的疗愈、支持、讲解、引导、总结或安抚意图。
- 叙事同台镜群 2–4 镜形成可读的关系发展（信息图讲解镜不计入），起点、转折和落点由文案安排，动作顺序随关系自然展开。

## 判断标准

- 删除大圣后，灵体仍然困在原地。
- 动作做完后问题没有消失。
- 大圣有入口、动作和对象。
- 两个身影确实连上或形成清晰的姿态关系。
- 大圣没有脱离本镜意图的夸张表演、替灵体解决问题或抢走画面焦点。

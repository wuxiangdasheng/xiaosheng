# 灵体

本文件是灵体的唯一权威：身份、状态、扮演、外观与判断。

## 他是谁

灵体是宇宙间的一个学习体。主叙述者是大圣，也是他的老师：叙述与命题出自大圣，扮演与学习由灵体完成。扮演是他学习的方式——进入某个场景中的人、物，就会生出那个处境下正常人应有的反应，所以画面里的情绪与反应都是真实的。灵体自己不经历任何事；文案说"你"、说某个人物、讲一个道理，都由他扮演。

他是画面里唯一的常驻存在者和唯一有进度的角色：不是符号、光效，也不是大圣的内心投射。他沉默，但会表达需要——攥、停、低头、缩、伸手、挪过去、仰头看；不说话、不劝人，也不替大圣做决定。

## 两个维度

他与内容背景分属两个维度：他扮演谁，谁就从背景中被他点亮、提到前景。被扮演者以"形"承接两个维度——形属于内容背景，质属于灵体。

## 状态与扮演

| 状态          | 大圣       | 灵体                          |
| ----------- | -------- | --------------------------- |
| 独演（solo）    | 画外叙述，不入画 | 独自演出叙述所指的人、物或概念             |
| 同台（onstage） | 入画，与灵体同场 | 叙事同台：以默认态接受指引与陪伴；信息图镜：担任提示员 |

同台描述的是“谁在场上”；陪伴是同台之下的行为之一（靠近、等待、并肩），不是状态名。

扮演对象（role）决定形态：

| role         | 形态                                              |
| ------------ | ----------------------------------------------- |
| 自己（含文案中的"你"） | 默认态出演；形体贴合本镜内容变形时，不改变紧凑比例                       |
| 人物名          | 变形为该人之形；手脚保持火柴人原样；服装、特征、道具按原文不变                 |
| 物名           | 变形为该物之形；不画手脚，白点眼保留在形体的朝向面上；形体顺应其自然姿态（飞行横陈、悬浮安放） |
| 概念名          | 形体贴合概念变化，与概念装置互动（见 `references/概念装置.md`）                   |

通用规则：

- 组成永远是灵体的半透明材质；现实道具、服装与特征按原文不变。
- 白色圆点眼在任何角色上都保留——演员的签名。保留的是**眼白圆点这个底子**：闭眼时收成两道弧线，仍认得出；眼仁有无、睁闭与视线是表情的载体，随状态与所扮角色变化（桥望着她的背影=凝望，分子赶时间=急切，"你"被压住=低垂）。
- 相邻单元的叙述主语相同（同一颗彗星、同一个分子）时，扮演对象默认延续，直到原文主语切换。
- 一个单元内状态与角色一致；单元间转场由灵体卸下或进入角色完成。
- 信息图镜中他担任提示员：用变形把讲解重点变成图元本身，或变成箭头、圈选、下划线等记号，协助大圣点亮信息。
- 扮演标注不进生成提示词与画面；需要注明"灵体扮演谁"时，由后续排版或剪辑工序以图注添加。

## 【进提示词】

固定块描述的是默认态（见下）；扮演或记号化变形时，由 `03-组装生图提示词.md` 的衔接句声明覆盖。独演镜逐字放在 `references/风格.md` 事实风格块之后；叙事同台镜接在同台风格块与大圣短识别词之后；信息图镜接在事实风格块与大圣短识别词之间。

```text
固定的灵体角色，默认形态：
身形——小而紧凑，轮廓略不规则的清晰手绘小生物，平涂，圆润半透明的暖黄团块，气质荒诞讨喜。
面部——白色圆点眼睛配黑色眼仁；嘴可有可无。
四肢——火柴人般的手脚，极细黑色单线，没有宽度与厚度，不是身体的小突起。
变形——需要动作时轮廓夸张变形、贴合当前状态（对抗时变矩形，压力大时拉成细高条），但四肢始终短小，紧凑比例不变；表情多变。
表演——它承担每一镜的核心动作：认真、笨拙、忙碌，带一点讨喜的荒诞感。
```

## 视觉不变量

- 半透明暖黄平涂，透明度一致，轮廓硬而略不规则；身体小而紧凑。
- 四肢极短：有夸张动作时手可适当变长，腿不可以。
- 四肢火柴人般的手脚，没有宽度与厚度，不是身体的小突起。
- 眼睛略大、间距较近，黑色眼仁控制视线方向。
- 不加入复杂服装或装饰花纹（role 为人物名、物名时，保留原文的服装与特征）。
- 灵体是画面唯一暖色主体；叙事同台镜另有一处淡暖白光源。

## 表演

- 默认态（自己/"你"）的表演词汇沿"经历 → 守着 → 找 → 停 → 收"推进：经历（听看吃嗅尝，忙晕对抗迷失）、守着（攥按抱压埋）、找（翻扒拨掏捋）、停（停住悬着僵住卡住）、收（递放松推让开）。扮演时的动作从所扮演的角色取——彗星就飞、就弹、就汽化，分子就反应、就赶时间，人物做该人物的事。
- 三档是每镜的心理档位标注，不是跨单元的强制推进线：单元内的状态弧有起点与落点（故事、观点、感悟单元），相邻镜不重复同一档；跨单元档位随该单元内容而定，转折处允许回退一档，信息图提示员镜不占档。
- 档是演员的能量档：身体表现按所扮角色转译，眼睛规则保留。

| 档           | 演员档位             | 身体（默认态）      | 眼睛          |
| ----------- | ---------------- | ------------ | ----------- |
| `scattered` | 收着的：费力、被动、被压着    | 压扁、蜷缩、前倾、细高条 | 无眼仁，看地面     |
| `gathering` | 接上的：注意到对象，开始试探用力 | 抬起一点、半展开     | 眼仁看向对象或递来的手 |
| `formed`    | 打开的：胜任、自在、有位置    | 舒展、饱满、飘起     | 闭眼享受，或清醒平视  |

- 三档的睛态覆盖固定块的默认“黑眼仁”配置：scattered 无眼仁、formed 闭眼——都是签名底子之内的变化，与固定块不冲突。

转译示例（同一档在不同角色上的读法）：

- 彗星：scattered=被引力弹得散乱；gathering=上了借力轨道；formed=平稳滑行。
- 氰化氢分子：scattered=快被稀释冲散；gathering=反应线接上、赶时间；formed=完成结合。
- "你"（治愈语境）：scattered=被那件事压住；gathering=注意到陪伴与方向；formed=与那件事共处——它仍在，我有了位置，不是痊愈。
- 同台镜的陪伴发展弧：接受指引 → 试探参与 → 自己带着继续走——带着什么随本镜内容定（方向、方法，或那件事）；节奏随文案安排。
- 他要得出来：会伸手、会挪过去、会仰头。舒展是身体舒展，不是消失或变透明——半透明是材质，不是情绪。
- 原文明确存在关键物件时贯穿相关镜头；没有明确物件时不额外创造手持道具。

## 判断标准

- 去掉他，画面只剩空场景：他承担了叙事。
- 换成普通人物，画面不再成立：表演保留了灵体特质。
- 他在角色中的反应，是那个处境下正常人应有的反应。
- 每镜身体形状和眼睛朝向都有推进。
- 他不安慰大圣、不解决问题、不成为第二个施予者。

# 风格：画风不变量与固定块

## 不变量

以下规则任何单元类型、任何灵体状态不得突破：

- 16:9 横版手绘绘本；蓝色粗纹理纸面，克莱因蓝到亮群青，丙烯干刷与蜡笔纹理。
- 灵体是画面唯一暖色主体（叙事同台镜另有一处淡暖白光源）；外观由 `references/灵体.md` 描述块决定，永不垫图。
- 大圣出场必垫 `references/IP.jpeg`；提示词里只用短识别词。
- 所有物件与道具平涂或简洁线稿，扁平无体积，无真实材质、高光和立体阴影。
- 每镜一句 `scene_intent`；提示词结尾注明景别（取自 `references/排版.md`）。
- 灵体状态三档（`scattered` / `gathering` / `formed`）是全片推进的通用工具。

## 事实风格块（独演镜使用；逐字进入提示词）

```text
现代极简绘本插画风，16:9 横版。蓝色粗纹理纸面，克莱因蓝到亮群青的轻微丙烯干刷、蜡笔纹理。画面安静、克制、松弛、低装饰、低细节，保留必要的事实场景和物件。

这是事实情节：场景必须来自原文，具体地点、人物、项目、设备、物件和正在发生的动作都要保持可辨认。环境服务于事件，不把事实物件抽象成隐喻；画面围绕灵体与那件事的具体互动组织，确保观众能看见它正在做什么，以及那件事给出的回应。

场景物件使用蓝色系线稿，深蓝到亮群青有层次，不填大面积暖色，不加入无功能装饰。灵体是画面中唯一的暖黄主体，暖黄是平涂颜色，和蓝色纸面形成清楚对比。

所有物品和道具都用平面色块或简洁线稿表现，保持扁平、无厚度、无立体建模感；不表现真实材质、体积塑形、强烈明暗阴影、金属高光或照片式细节。

构图服从事实的可读性：根据地点、物件和动作选择合适的近景或中远景，不为追求微缩感而缩小关键对象；保留足够空间看清主要设备、物件、人物关系和可见回应。不要写实、材质不要拟物，保留手绘感。
```

## 同台风格块（叙事同台镜使用；逐字进入提示词）

```text
现代极简绘本插画风，大面积同色系连续环境主导画面；背景极度简化，只保留少量必要景物；人物微缩，人物主体高度不超过画面高度的 20%，与宏大环境形成清晰尺度反差；整体安静、松弛、带诗意孤独氛围；使用非对称的大面积负空间留白；主体轮廓简练概括；保留手绘笔触、粗纹理纸面质感、蜡笔与丙烯干刷纹理。画面以克莱因蓝为主色，环境是画面主体，人物通过姿态、距离和轮廓关系表达动作。
所有环境物品和道具都采用平涂色块或简洁线稿，保持扁平、无厚度、无立体体积；不表现真实材质、体积塑形、强烈明暗阴影、金属高光或照片式细节。
```

## 同台造景（叙事同台镜；信息图镜用图解版式）

根据内容单元真正要带来的变化，创造一个能承接转折和关系变化的开阔隐喻环境。重点是让空间呈现此刻正在发生的转变。

造景规则：大远景需要的是环境主导，不是环境缺席——每个同台镜的环境必须点名**一个具体地点 + 2–3 个特征物 + 地面材质**（从下表选或新造，新造先登记）；"开阔"由尺度与留白实现，不由空旷实现。除非隐喻语义本身指向草地，否则不使用草地、原野、田野。

| 地点 | 特征物 |
| --- | --- |
| 寺庙寺院 | 石阶、飞檐、经幡、铜钟 |
| 古镇街道 | 石板路、灯笼、屋檐 |
| 屋顶天台 | 矮墙、天窗、远处城市轮廓 |
| 海边 | 礁石、灯塔、浪线 |
| 树林 | 树影、光斑、苔石 |
| 音乐厅 | 座席、舞台、吊灯 |
| 星空天文台 | 山顶平台、望远镜穹顶、星轨 |
| 空房间 | 窗、光斑、一把椅子 |
| 雪原 | 枯树、远山、雪纹 |
| 湖面栈桥 | 栈桥、水面倒影 |

让环境对内容产生可见回应：空间因为陪伴、理解、安置或重新组织而发生变化，例如风把压低的云层稍稍推开、水面恢复平静、断开的路径重新连上。

保持大面积环境、简洁线条和充足留白，只保留能认出空间并承接动作的必要景物。叙事同台镜表现当下的陪伴和转变，不画成问题已经解决。

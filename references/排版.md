# 排版：构图与景别

本文件是景别与构图规则的唯一权威。

## 景别体系

| 景别       | 规则                               | 默认用途          |
| -------- | -------------------------------- | ------------- |
| 大远景（微缩）  | 环境主导，人物主体高度不超过画面高度的 20%，非对称大面积留白 | 叙事同台镜默认       |
| 中远景 / 中景 | 保证装置关系、人物动作和可见回应清晰可读             | 概念装置、事实还原场景默认 |
| 中近景      | 保证手部动作、接触点和物件细节可读                | 方法单元操作镜、步骤镜默认 |

## 构图原则

- 构图服从可读性：不为风格感牺牲关键物件和动作的清晰度，不为追求微缩感而缩小关键对象。
- 画面流向一致：步骤、条目类内容统一从左到右或从上到下推进，用构图暗示顺序。
- 留白：环境主导场景保留大面积负空间；事实场景保留看清"动作 → 回应"的空间。
- 物件摆位体现先后：用过的物件留在画面一侧，物料按使用顺序就位。
- 环境对内容产生可见回应：空间、物件随动作发生变化，不做静态明信片。

## 系列一致性

- 同一单元的镜群保持同一景别基调；单元之间允许景别切换来标记转场。
- 条目、步骤类内容用构图变化（角度、距离、背景物）区分镜与镜。
- 景别配合灵体状态：`scattered` 多近观，`formed` 多开阔。

## 图解版式（信息图镜）

- 版面分区：一张版面承载一个信息主题；条件、步骤、对比用分区或分栏呈现，区块间留呼吸空隙。
- 标注规范：文字标注紧贴对应图元，引线短而直、不交叉；箭头表达方向与因果，一个箭头只说一件事。
- 人物位：大圣担任讲解者，指向当前重点；灵体作为提示员待命，讲到即变形——成为图元本身，或成为圈选、下划线、箭头等记号把重点点亮。
- 数据诚实：数量、比例、年份只画原文给出的；对比用大小、疏密、长短暗示，不添加原文没有的刻度与数字。
- 标注用短标签：每条不超过约 8 字；长句语义交给图元形态与分区承担。
- 版式节奏：相邻信息图镜切换版式方向（横排↔上下对照、双栏↔单幅），避免连续同构图。

### 版式用例

| 版式   | 适用信息       | 版面特征               | 人物位                  |
| ---- | ---------- | ------------------ | -------------------- |
| 时间轴式 | 演变、频率、先后   | 横轴或纵轴串起事件，点的疏密就是信息 | 大圣站轴尾指向；灵体圈选关键节点     |
| 双栏对照 | 二元对比、两种来源  | 左右两区，中缝留白          | 大圣居中偏一侧逐栏讲；灵体逐栏点记号   |
| 上下对照 | 大小、厚薄、层级对比 | 上下两区，尺寸比例暗示差异      | 大圣站版侧指上/下层；灵体划线      |
| 中心辐射 | 一个核心带多个分支  | 主体居中，分支向四周辐射       | 大圣站中心旁讲；灵体趴在某分支上点亮它  |
| 流程阶梯 | 步骤、因果、递进   | 台阶或 S 形路径，箭头衔接     | 大圣站起点讲；灵体站在当前那一阶上    |
| 清单卡片 | N 个并列要点    | 手绘卡片成排，一卡一物一签      | 大圣沿列巡讲；灵体逐卡互动，动作各不相同 |
| 放大特写 | 全景中的一个关键细节 | 全景 + 虚线放大圈         | 大圣持圈讲解；灵体钻进放大圈里演细节   |
| 剖面分层 | 结构、成分、内外   | 主体切开或分层展示          | 大圣指层；灵体站进剖面里         |

选用规则：按信息结构选最贴合的版式；用例可组合、可新造，新造先在此登记。相邻信息图镜必须换版式；同一版式全片最多出现两次。灵体的提示员变形跟随版式变化（圈选、划线、站上台阶、钻进放大圈、趴上分支）。

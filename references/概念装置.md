# 概念装置：把概念画成可画的形象

概念单元的"画什么"由概念装置承担：把抽象概念具象成蓝色线稿的可交互形象。

## 生成方法

把抽象概念画成可画形象的方法：**问这个概念在做什么——它的功能动词是什么——把那个动词翻译成一个可画的物件或结构。**

推导步骤：

1. 找到概念的功能动词：它**阻碍**了什么？**承载**了什么？**聚焦**了什么？**分隔**了什么？**注入**了什么？**指引**了什么？
2. 把那个功能动词翻译成一个可画的物件或结构形式
3. 让灵体进入或使用这个物件，让它对灵体产生可见回应

示例（示范推导感觉，不封选项）：

- 功能是**阻隔** → 坝、闸、墙、锁
- 功能是**承载** → 台座、手掌、桥、地面
- 功能是**聚焦** → 光束、透镜、漏斗口
- 功能是**计时** → 刻度线、天文仪、沙漏
- 功能是**更替** → 拼块、碎片、空位、蜕壳
- 功能是**关系** → 气息线、连线、桥索
- 功能是**指引** → 窗、门、箭头路标
- 功能是**包含** → 大轮廓、容器、巢

## 用法规则

- 扮演对象优先选动作的发出者——谁在动就演谁；纯状态、无动作的概念才整体落为装置形态。
- 每镜绑定一个概念要点，一个装置承载一个概念，不跨镜混用。
- 灵体扮演该概念：它站在装置里、与装置互动，装置对它产生可见回应（轮廓环抱、虚线延伸、光束亮起、碎片掉落）。
- 概念画成"正在被经验"，不画成"已经被解决"。
- 灵体形体可贴合概念变形（矩形=对抗、细高条=压力、纯能量光点=无形等），全片特殊形体不超过一处。
- 装置场景景别默认中景、中远景；概念尺度极大时用大远景（微缩）。

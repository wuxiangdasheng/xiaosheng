# xiaoshengcomic：工作流源文件目录

星巢绘本配图工作流的源文件。工作流是三步主干加按需延伸；技能包由本目录整体发布 —— `SKILL.md` 是主干摘要，`01`–`06` 是逐步细则，规则本体在 `references/`。

## 工作流

| 节点              | 做什么                 | 产出              |
| --------------- | ------------------- | --------------- |
| `01-拆解重组文案.md`  | 把文案拆成内容单元，按讲述需要重排顺序 | 有序内容单元表         |
| `02-决定画什么.md`   | 按成片顺序逐单元决定镜头，写镜头卡   | 镜头卡序列 + 角色与扮演登记 |
| `03-组装生图提示词.md` | 从资源文件取块，拼装纯文本提示词    | 提示词序列           |
| `04-出图.md`（按需）  | 垫图生成成图              | `images/`       |
| `05-视频.md`（按需）  | 图生视频 / 文生视频提示词与生成   | `videos/`       |
| `06-交付与质检.md`   | 落盘、用户分支、逐镜质检、回退     | 交付目录            |

## 资源库

节点只做流程，规则本体放在资源文件里；缺什么补什么，新增资源先登记再使用。

| 资源           | 内容                                  |
| ------------ | ----------------------------------- |
| `references/风格.md`   | 画风不变量、事实风格块、同台风格块、同台造景              |
| `references/灵体.md`   | 灵体外观描述块、功能与状态（独演/同台 + role）、动作与判断标准 |
| `references/大圣.md`   | 大圣外观校准与短识别词、同台动作、行为边界               |
| `references/排版.md`   | 景别体系、构图原则、系列一致性                     |
| `references/概念装置.md` | 概念装置词汇表与用法                          |

## 约定

- 每个节点文件以「输入 / 动作 / 产出 / 失败回退」组织。
- 每条规则只在一个文件里定义，其余文件引用，不改写。
- 穿线主体是灵体：单元之间不依赖时间或因果连续，转场由灵体的状态与角色切换承担。
- 规范批量修改后，按 `规范审查清单.md` 执行六遍扫描（模型对齐、术语一致、接线、读者分层、重复与残句、覆盖对齐），结果记台账。
